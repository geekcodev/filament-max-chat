# v1.0.3

## Нововведения

- **Аватар пользователя в заголовке чата.** Рядом с именем отображается круглая аватарка (фото или инициалы) — как в
  списке диалогов.

- **Модалка с информацией о пользователе.** По клику на имя в заголовке открывается Alpine-модалка: по центру большая
  аватарка, Имя Фамилия, ID пользователя. Закрывается по клику на backdrop, кнопке «Закрыть» или Escape.

## Улучшения

- **Кнопка удаления сообщения** перенесена внутрь пузыря сообщения (прижата к верхнему правому углу). Иконка заменена на
  серую корзину (`heroicon-o-trash`) — визуально единообразна с кнопкой очистки всего чата. При наведении плавно
  проявляется и становится красной.

- **Badge уведомлений** теперь рендерится нативно в Filament sidebar через `.fi-badge` вместо кастомного `<span>`.

- **Подавление уведомлений в активном чате.** Звук, toast и browser notification не срабатывают, если оператор уже
  открыл диалог, из которого пришло сообщение.

- **Отложенный запрос разрешения на уведомления.** `Notification.requestPermission()` вызывается при первом клике
  пользователя, а не при загрузке страницы.
