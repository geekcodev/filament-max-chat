# v1.0.6

## Исправления

- **Счётчик непрочитанных и уведомления теперь работают на всех страницах админки.** Раньше обновление бейджа и звук со
  toast/browser-уведомлением приходили только двух путях: событие Echo `chat-message.created` и DOM-событие
  `chat-unread`, которое диспатчит Livewire-компонент лишь на странице чата. На остальных страницах панели не было ни
  одного периодического запроса, и счётчик в сайдбаре не обновлялся, пока вы не перезагрузите страницу. Добавлен
  глобальный HTTP-poll: новый эндпоинт `GET /admin/chat/unread-count` (`UnreadCountController`) отдаёт JSON
  `{unread_count, latest_bot_chat_id}`, а скрипт уведомлений опрашивает его на всех страницах и обновляет бейдж.

- **Звук/toast больше не срабатывают на собственные исходящие сообщения.** Раньше уведомление появлялось на каждое
  событие Echo, включая ответы оператора. Теперь оповещение срабатывает только когда счётчик непрочитанных вырос —
  собственные отправленные сообщения его не увеличивают.

- **Двойные уведомления от Echo и poll исключены.** Единая функция обработки сверяет последнее известное значение
  счётчика и играет сигнал только при его росте, поэтому событие real-time и периодический опрос не дублируют показ.

## Улучшения

- Подавление для «активного чата» распространяется и на poll: если последнее непрочитанное сообщение пришло из открытого
  сейчас диалога, звук не играет (вы и так его видите), но бейдж обновляется.

## Конфигурация

Новые опции в `config/filament-max-chat.php`:

| Ключ                                  | Что делает                             | По умолчанию               |
|---------------------------------------|----------------------------------------|----------------------------|
| `route.unread_count_uri`              | Путь эндпоинта счётчика непрочитанного | `/admin/chat/unread-count` |
| `notifications.poll_enabled`          | Включить HTTP-poll фолбэк к Echo       | `true`                     |
| `notifications.poll_interval_seconds` | Интервал опроса                        | `15`                       |
