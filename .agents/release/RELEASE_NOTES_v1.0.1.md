# v1.0.1

## Исправления

- **Сброс file input после отправки.** После отправки вложения инпутов очищался на сервере, но продолжал отображать
  имя файла в браузере. Добавлен `wire:ignore` и Alpine `x-effect` для корректной очистки DOM.

- **Кнопка удаления сообщения не появлялась.** Кнопка `×` на сообщениях была скрыта через `hidden` (`display: none`),
  который перебивал `group-hover:flex`. Заменена на `opacity-0` + `pointer-events-none` с плавным появлением при
  наведении.

- **Заголовок страницы.** «Чат оператора» / «Operator chat» переименован в «Чат» / «Chat».
