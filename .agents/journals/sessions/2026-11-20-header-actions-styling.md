# Стиль кнопок шапки чата

## Проблема

В шапке чата соседствовали две группы кнопок с одинаковым видом: действия из конфига хоста (`actions.header`, в примере
«Создать заявку» с `heroicon-o-document-plus`) и встроенные «Удалить чат» (`heroicon-o-x-circle`) и «Очистить историю»
(`heroicon-o-trash`). Все были без рамки, серые, с красным фоном на hover. Из-за этого мягкое удаление из списка и
необратимая очистка истории выглядели одинаково опасными, а шапка (32px без рамки) расходилась по стилю с рядом
форматирования (28px с рамкой). Подпись «Удалить чат» обещала больше, чем происходило: история и вложения сохраняются.

## Решение

Шапка стала единой системой: кнопки высотой 32px с рамкой, скруглением и `focus-visible`-кольцом. Смысл кодируется
цветом:

- действия хоста — нейтральный серый контур по умолчанию; пример «Создать заявку» задаёт primary через `class`;
- «Убрать из списка» — amber и `heroicon-o-archive-box-x-mark`: действие обратимое, история остаётся;
- «Очистить историю» — red и `heroicon-o-trash`: единственное необратимое действие;
- перед группой опасных кнопок — вертикальный разделитель, только если есть действия хоста.

У всех иконок добавлен `aria-label` (раньше был только `title`), у ссылок действий тоже. Дефолтный набор классов кнопки
хоста заменил прежний безрамочный; ключ `class` в конфиге по-прежнему заменяет стиль целиком, поэтому старые конфиги не
ломаются, а пример `config-actions.php` обновлён под новую палитру.

## Тесты

Два feature-теста в `OperatorChatTest`: встроенные кнопки имеют `aria-label` и классы `border-amber-200`/
`border-red-200`; действие хоста без `class` получает дефолтную серую рамку и рядом появляется разделитель `h-5 w-px`.

## Нюансы

Текст ключа `remove_chat` изменён на «Убрать из списка» / «Remove from list» — это подпись, а не публичный API, и она
теперь совпадает с подтверждением и фактическим поведением. Кнопки без иконки в дефолтном стиле растягиваются по тексту
(`min-w-8` и `px-1.5`), поэтому текстовые действия хоста не обрезаются. Разделитель выводится по непустому списку
действий, иначе опасная группа начиналась бы с висящей черты.
