# Документация без привязки к сторонним хост-проектам

## Проблема

Пользователь: пакет не должен упоминать проекты, в которых он установлен (например, конкретные хост-приложения) —
документация описывает кейсы, а не чужие внедрения. Упоминания были разбросаны по README (changelog v1.1.7), AGENTS.md
(gotcha 22), докблоку `ContactWithoutHashWebhookTest` и рабочей памяти `.agents/` (планы, журналы, release-notes v1.1.1
и v1.1.7 — всего 16 файлов, 34 вхождения).

## Решение

Массовая замена `sed`-скриптом с сохранением смысла кейса: «в <проект>» → «в хост-приложении», «Из хоста <проект>» → «Из
хост-приложения», «приложение-<проект>» → «хост-приложение», «проектный фикс <проект>» → «проектный фикс хоста» и
аналогичные варианты с разными падежами. Техническая ценность записей (SQLSTATE 42P10, прод-зависание, регрессия
контакта без `hash`) сохранена полностью — убрана только привязка к названию проекта. В release-notes v1.1.7 добавлена
строка в «Качество» о чистке документации.

## Тесты

Правки только в `.md` и одном докблоке `tests/Feature/ContactWithoutHashWebhookTest.php` — поведение не менялось, но по
правилам перепрогнан быстрый круг Gate: lint 0/60 · PHPStan level max 0 · 368 тестов / 946 проверок · покрытие 97.60%
(порог 95%) · `composer audit` чист. Шаг 7 и аудит зависимостей не менялись (composer.json не трогался).

## Нюансы

Финальная проверка поиском имён по репозиторию: в коде, README, AGENTS.md и `.agents/` — 0 совпадений. Два остатка вне
зоны документации: `.phpstan-cache/` (киш, gitignore, пересобран прогоном Gate) и
`.idea/workspace.xml` (локальное состояние IDE пользователя, не в git) — не документы, не трогались. Важно: `AGENTS.md`
попадает в архив Packagist (нет `export-ignore` в `.gitattributes`), поэтому его чистка обязательна наравне с README;
`.agents/` в dist не попадает, но чищен по запросу «все документы».

## Gate

Быстрый круг (шаги 1–6): lint 0/60 · PHPStan 0 · 368/946 · покрытие 97.60% · audit чист (`COMPOSER_IPRESOLVE=4`). Шаг 7
не прогонялся — composer.json и требования PHP не менялись. Коммиты не создавались.
