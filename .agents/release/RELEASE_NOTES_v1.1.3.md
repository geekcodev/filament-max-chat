# v1.1.3

Патч делает страницу чата оператора пригодной на телефоне. Сейчас на узком экране список диалогов и переписка ужимались
в две колонки, поэтому ни ленты, ни поля ввода видно не было. Ломающих изменений нет — правки только в разметке и в
одном ключе перевода.

## Что было сломано

Страница чата рисовалась одной flex-строкой: список диалогов фиксированной ширины (`w-80`) плюс панель переписки
`flex-1`. На экране телефона ширины не хватало, и панель переписки — лента, поле ввода и кнопки форматирования —
оказывалась за пределами видимой области, а список занимал весь экран. Десктопная раскладка при этом работала корректно.

## Новое

**Одноколоночная вёрстка на мобильном.** Список диалогов и переписка показываются по очереди. Без выбранного чата список
занимает всю ширину (`w-full`), а панель переписки скрыта (`hidden md:flex`). После выбора чата список сворачивается
(`hidden md:block`), лента и форма ответа занимают весь экран, а в шапке появляется кнопка возврата к списку
(`wire:click="$set('activeChatId', null)"`, видна только на мобильном через `md:hidden`). Высота под мобильную версию
увеличена (75vh против 70vh на десктопе), промежуток между панелями уменьшен.

Логика Livewire не ветвится: видимость панелей выводится из уже существующего состояния `activeChatId`. Добавлен один
ключ перевода `back_to_list` («К списку диалогов» / «Back to conversations») в `lang/ru` и `lang/en`.

На широком экране поведение не изменилось — список и переписка стоят рядом в две колонки.

## Изменение (BC)

Ломающих изменений нет: публичные сигнатуры, ключи и значения по умолчанию конфига не менялись. Добавлен новый ключ
перевода `back_to_list`; существующие ключи не переименованы и не удалены. Новых переменных окружения нет.

## Затронутые сценарии

- Мобильный экран: список диалогов и переписка переключаются по выбору чата; лента, поле ввода, вложения и кнопки
  форматирования занимают всю ширину, возврат к списку — кнопкой в шапке.
- Планшет и десктоп: поведение прежнее — две колонки рядом.
- Панель без выбранного чата: на мобильном виден только список; на десктопе в правой колонке остаётся подсказка
  «Выберите диалог слева».
