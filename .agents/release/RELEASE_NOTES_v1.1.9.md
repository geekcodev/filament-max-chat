# v1.1.9

Патч исправляет отправку запроса контакта: MAX отклонял сообщение с клавиатурой `request_contact`, у которого не было
текста. Сообщение теперь уходит с текстом, кнопка и её подпись не меняются. Публичные сигнатуры не менялись.

## Новое

- Отдельный текст сообщения для запроса контакта: `filament-max-chat::chat.request_contact_prompt`
  (ru: «Пожалуйста, поделитесь контактом.», en: «Please share your contact.»). Подпись кнопки (`request_contact_button`)
  не меняется.

## Изменение (BC)

- Публичные сигнатуры не менялись. `MaxChatSender::sendRequestContact(Recipient, string $buttonText, ?string $text)`
  остаётся прежней.
- Поведение: сообщение с клавиатурой `request_contact` всегда уходит с непустым текстом. Если `text` не передан, в
  качестве текста используется подпись кнопки, без HTML-разметки.
- Поведение: в историю переписки оператора теперь пишется текст сообщения (`request_contact_prompt`), а не подпись
  кнопки. Записи, сохранённые в предыдущих версиях, не меняются.

## Затронутые сценарии

- Оператор нажимает «Запросить контакт» в чате, где у собеседника нет телефона. Ранее MAX отклонял такое сообщение с
  ошибкой `errors.required` (в логе: «failed to send request_contact to MAX»), теперь сообщение и кнопка уходят.
- Ручная отправка `MaxChatSender::sendRequestContact()` без текста из хост-приложения.
- Примеры в `examples/send-request-contact.md` приведены к реальной сигнатуре `sendRequestContact()`.
