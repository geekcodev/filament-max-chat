# v2.0.0

Синхронизация с ядром `geekcodev/max-php-client` **v2.0.0** и адаптером `geekcodev/laravel-max-client` **v2.0.0**.
Версия ломающая: события MAX приходят типизированными, вложения и кнопки — отдельными классами. Зависимости выпущены
тегом `v2.0.0`, серверная проверка вебхуков в тестовом проекте пройдена 2026-11-23.

## Новое

- `MaxMessageService` принимает конкретные подтипы `Update` вместо плоского события: `MessageCreatedUpdate`,
  `MessageEditedUpdate`, `MessageRemovedUpdate`, `DialogClearedUpdate`, `DialogRemovedUpdate`,
  `ChatTitleChangedUpdate`. Слушатель `HandleIncomingMaxUpdate` ветвится по `instanceof`.
- Вложения читаются типизированными классами ядра (`PhotoAttachment`, `VideoAttachment`, `AudioAttachment`,
  `FileAttachment`, `StickerAttachment`, `ContactAttachment`, `LocationAttachment`, `ShareAttachment`,
  `InlineKeyboardAttachment`) — метаданные карточки не изменились.
- Исходящие вложения собираются через `PhotoAttachmentRequest`, `VideoAttachmentRequest`, `AudioAttachmentRequest`,
  `FileAttachmentRequest` и `InlineKeyboardAttachmentRequest` с `Keyboard` и `RequestContactButton`.
- Номер телефона из контакта извлекается только из `vcf_info` (`vcfPhone` удалён в ядре v2.0.0).
- Кнопка «Запросить контакт» показывается не только при пустом телефоне, но и когда номер не подтверждён
  (`max_users.phone_verified_at` пуст): заполненный другим путём номер нельзя считать верным, поэтому оператор может
  запросить подписанный контакт повторно.
- Ссылка вложения-геолокации ведёт на Яндекс Карты (`yandex.ru/maps`) вместо OpenStreetMap.
- Шапка чата: кнопки действий стали контурными 32×32 с осмысленным цветом — primary у действий хоста, amber у «Убрать из
  списка» (история сохраняется), red у «Очистить историю» (необратимо). Перед группой опасных кнопок появился
  разделитель, у иконок — `aria-label`. Подпись «Удалить чат» заменена на «Убрать из списка», чтобы совпадать с
  фактическим поведением.
- Карточка собеседника в шапке показывает телефон из `max_users.phone` ссылкой `tel:`: подтверждённый подписанным
  контактом номер — без пометки, неподтверждённый — с пометкой «не подтверждён», отсутствующий — «не указан». Сама
  карточка объявлена диалогом (`role="dialog"`, `aria-modal`, `aria-labelledby`), фокус заперт внутри через
  `x-trap.noscroll`, прокрутка фона блокируется; кликабельны и аватар, и имя, а при неподтверждённом номере внутри есть
  кнопка «Запросить контакт».

## Изменение (BC)

- Constraints: `geekcodev/max-php-client` `^1.1.11` → `^2.0`, `geekcodev/laravel-max-client` `^1.2.3` → `^2.0`.
- Переменные окружения переименованы под схему `laravel-max-client` и `filament-max-broadcasts`: `FILAMENT_MAX_CHAT_*` →
  `MAX_CHAT_*` (канал — `MAX_CHAT_BROADCAST_CHANNEL`, вложения — `MAX_CHAT_ATTACHMENTS_*`, `login_url` и
  `unread_count_uri` — `MAX_CHAT_ROUTE_*`), права — `MAX_PERMISSION_CHAT_VIEW` / `MAX_PERMISSION_CHAT_ANSWER`. Строки
  прав по умолчанию стали `max_chat.view` / `max_chat.answer` вместо `chat.view` / `chat.answer`; `max_chat.view`
  совпадает с правом реестра чатов адаптера. Старые имена переменных не поддерживаются, ключи конфига не менялись.
- Публичные методы `MaxMessageService` принимают типизированные подтипы `Update`. Код приложения, передававший плоский
  `Update`, требует правок.
- `MessageBody::$caption` больше нет: правка сообщения обновляет только текст.
- Видео не скачивается на приватный диск: карточка показывает тип вложения, файл остаётся в MAX.
- Невозможные в типизированной модели сценарии удалены из тестов: lifecycle-апдейт без `chat_id`/`user` и вложение с
  пустым `payload` (такие payload отклоняются разбором ядра).

## Затронутые сценарии

- **История переписки**: создание, правка, удаление сообщения, очистка и удаление диалога, смена названия — поведение
  прежнее, изменился только способ ветвления.
- **Ответ оператора файлом или картинкой**: загрузка через `uploadMedia` возвращает `UploadEndpoint`; для картинки
  используется `token`/`url`, для остальных типов — `token` (`UploadedInfo`).
- **Кнопка «Поделиться контактом»**: клавиатура собирается типизированными классами, текст-заглушка сохранена.
- **Карточка контакта**: имя из `max_info`/vCard, телефон из `vcf_info`; неподписанный контакт по-прежнему не
  подтверждается.
- **Обновление установки**: перенести `FILAMENT_MAX_CHAT_*` на `MAX_CHAT_*` (таблица соответствия — в README, раздел
  «Обновление до v2.0.0»), выдать ролям `max_chat.view` / `max_chat.answer` и обновить опубликованный конфиг, если он
  есть.
