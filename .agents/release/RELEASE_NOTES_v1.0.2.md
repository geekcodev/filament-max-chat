# v1.0.2

## Улучшения

- **Broadcast-канал переименован** из `operator.chat` в `chat.channel` — нейминг больше не привязан к роли оператора.

- **Бейдж уведомлений в sidebar.** Badge теперь рендерится нативно в Filament sidebar (`.fi-badge`) вместо кастомного
  `<span>`, что делает его визуально единообразным с остальными бейджами панели.

- **Подавление уведомлений в активном чате.** Если оператор уже открыл диалог, из которого пришло сообщение — звук,
  toast и browser notification не срабатывают. Отслеживание активного чата через `dispatch('chat-active')` в Livewire и
  `window.__fmcActiveChatId` на клиенте.

- **Отложенный запрос разрешения на уведомления.** Браузерный `Notification.requestPermission()` вызывается при первом
  клике пользователя, а не при загрузке страницы — исключает блокировку браузером за незапрошенный弹窗.

## Исправления

- **Сброс file input после отправки.** Инпут файлов очищался серверно, но продолжал отображать имя файла в браузере.
  Добавлен `wire:ignore` + Alpine `x-effect` для корректной очистки DOM.

- **Кнопка удаления сообщения не появлялась.** Кнопка `×` была скрыта через `hidden`, который перебивал
  `group-hover:flex`. Заменена на `opacity-0` + `pointer-events-none` с плавным появлением при наведении.

- **Заголовок страницы.** «Чат оператора» / «Operator chat» переименован в «Чат» / «Chat».
