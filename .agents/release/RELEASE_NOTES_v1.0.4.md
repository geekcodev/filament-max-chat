# v1.0.4

## Исправления

- **Бейдж уведомлений не появлялся.** CSS-селектор `a[href$="/chat"]` не совпадал с DOM Filament v5 — ссылка в sidebar
  использует класс `.fi-sidebar-item-btn`. Селектор исправлен, бейдж теперь создаётся и обновляется корректно.

- **Кнопка «Убрать файл» появлялась во время загрузки.** `wire:model` устанавливает `$attachment` сразу при выборе
  файла, и кнопка была видна до завершения загрузки. Добавлены Alpine + Livewire upload events (`upload:started` /
  `upload:finished`): кнопка скрыта через `x-show="!uploading"` пока идёт загрузка, после завершения — появляется.

- **Очистка file input после отправки.** Событие `clear-file-input` диспатчится из Livewire после `reset('attachment')`
  и слушается в Blade для очистки DOM-значения инпута.
