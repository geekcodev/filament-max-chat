# v1.0.5

## Исправления

- **Счётчик непрочитанных в сайдбаре снова отображается.** `restoreBadge()` на каждой загрузке страницы читал значение
  из `localStorage` (пустое → `0`) и убирал нативный бейдж, который рендерит Filament-sidebar через
  `getNavigationBadge()`. Теперь при инициализации счётчик берётся из серверного бейджа сайдбара, так что он больше не
  стирается.

- **Уведомления перестали молчать после просмотра диалога.** Подавление для «активного чата» держало `bot_chat_id`
  последнего открытого диалога в глобальной переменной и продолжало глушить звук/toast/browser-уведомление на любых
  других страницах админки. Теперь `__fmcActiveChatId` сбрасывается при уходе со страницы чата — уведомления снова
  приходят, даже если сообщение пришло из последнего просмотренного диалога.

- **Селектор бейджа соответствует конфигурируемому slug.** Поиск пункта меню теперь строится по слагу из конфига
  (`ui.slug`), а не по жёстко зашитому `/chat`.

## Улучшения

- **Бейдж обновляется в реальном времени.** После прочтения диалога, удаления или очистки сообщений Livewire диспатчит
  событие `chat-unread` с актуальным общим числом непрочитанных — счётчик в сайдбаре синхронизируется сразу, не
  дожидаясь следующего события или перезагрузки.
