# Доступность карточки собеседника и действия в ней

## Проблема

Карточка собеседника была обычным Alpine-блоком с `x-show`: без `role="dialog"` и `aria-modal`, без ловушки фокуса,
фокус при Tab уходил в страницу за модалкой, фон прокручивался под ней. В шапке кликабельным было только имя, аватар —
нет. Внутри карточки не было действий: запросить контакт можно было только кнопкой рядом с форматированием. В CSS
плагина отсутствовало правило `[x-cloak]`, поэтому до инициализации Alpine модалка могла мелькнуть.

## Решение

Панель модалки объявлена диалогом: `role="dialog"`, `aria-modal="true"`, `aria-labelledby` на заголовок с именем, где
идентификатор собирается из `getId()` компонента, чтобы не конфликтовать при нескольких экземплярах. На панель добавлен
`x-trap.noscroll="showUserInfo"`: это ловушка фокуса, блокировка прокрутки и возврат фокуса на триггер. Filament уже
подключает Alpine Focus — его собственные модалки используют тот же `x-trap`, новых зависимостей нет.

Кнопка-триггер получила `aria-haspopup="dialog"` и теперь оборачивает и аватар, и имя: один кликабельный элемент вместо
текста. Кнопка «Закрыть» и новое действие получили `focus-visible`-кольца. У телефона добавлен `break-all` на случай
длинного значения. В CSS плагина появилось правило `[x-cloak] { display: none !important; }`.

В карточке появилось действие «Запросить контакт» — только при праве `chat.answer` и неподтверждённом номере
(`canAnswer && canRequestContact`). Клик отправляет запрос через существующий `requestContact()` и закрывает карточку
(`@click="showUserInfo = false"`); серверная проверка права остаётся в методе.

## Тесты

Три feature-теста: наличие атрибутов диалога и `x-trap`, кнопка запроса контакта внутри карточки при неподтверждённом
номере (два вхождения `wire:click="requestContact"` — панель форматирования и карточка) и её отсутствие при
подтверждённом (ноль вхождений).

## Нюансы

JS-поведение (ловушка фокуса, Escape, блокировка прокрутки) PHPUnit не проверяет: тесты закрывают разметку и атрибуты,
реальную клавиатурную навигацию нужно смотреть в браузере. `x-trap` доступен потому, что компонент живёт в
Filament-панели; если когда-нибудь понадобится использовать его вне панели, потребуется подключить Alpine Focus
самостоятельно. Правило `[x-cloak]` работает только у хостов, которые импортируют CSS плагина, как и описано в README.
