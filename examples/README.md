# Примеры использования расширяемости filament-max-chat

Плагин позволяет добавлять кнопки в интерфейс чата без копирования Livewire-компонента.

## Способы

1. **Через конфиг `actions`** - декларативный, удобно для большинства случаев
2. **Через Blade-стеки** - максимально гибкий, можно вставить любой контент
3. **Через наследование Livewire** - для сложной логики

## Доступный контекст

В колбэках и в шаблонах доступны:

- `$chat` - `GeekCo\FilamentMaxChat\Models\MaxChat` (текущий диалог)
- `$chatUser` - `GeekCo\LaravelMaxClient\Models\MaxUser|null` (собеседник через `interlocutor()`)
- `$activeChatId` - ID чата
- `$component` / `$this` - экземпляр Livewire компонента

У `MaxUser` есть поля: `user_id`, `first_name`, `last_name`, `phone`, `email`, `username` и др.

## Системная кнопка "Запросить контакт"

В пакете по умолчанию добавлена кнопка "Запросить контакт" (рядом с кнопками форматирования), если:

- Есть собеседник `$chatUser`
- У собеседника нет телефона (`empty($chatUser->phone)`)
- У пользователя есть право `chat.answer`

При клике отправляется inline-клавиатура с кнопкой `request_contact` в MAX. После того как пользователь поделится
контактом, адаптер/ядро сохранят телефон в `MaxUser` (если включён соответствующий функционал).
