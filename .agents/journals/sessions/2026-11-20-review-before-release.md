# Ревизия партии перед v2.0

## Проблема

Перед выпуском нужно было проверить всю незакоммиченную партию (запрос контакта для неподтверждённого телефона, Яндекс
Карты, стиль шапки, телефон в карточке собеседника, обновление планов) на соответствие `AGENTS.md`, best practices и
требованиям production-grade.

## Решение

Проверены диф `src/`, `resources/`, `lang/`, `tests/`, `examples/` и документация. Публичный API не сломан: новые методы
только добавляют computed `canRequestContact()`, конфиг и переменные окружения не менялись, миграций нет. Права
fail-closed сохранены: страница и вложения по `permissions.view`, отправка и запрос контакта по `permissions.answer`;
`requestContact()` проверяет право на сервере независимо от видимости кнопки. Прямых вызовов `ApiClient` нет, отправка
идёт через `MaxChatSender`. Секретов и содержимого переписки в логах не появилось. Ключи переводов добавлены в оба
языка. Внешние ссылки используют фиксированную схему `https:`, вывод телефона экранируется Blade.

По ревизии исправлено три места. Нечисловые координаты из метаданных больше не попадают в URL карты: `is_numeric()` и
приведение к `float` не дают подмешать параметры в `pt`, при мусоре показывается прежняя заглушка «геолокация». Пометка
«не подтверждён» переведена с `amber-600` на `amber-700`: мелкий текст на белом фоне иначе не дотягивал до контраста AA.
Добавлены два теста: экранирование разметки в телефоне и отсутствие ссылки на карту при нечисловых координатах.

Осознанно оставлено как есть: `aria-label` дублирует текст у кнопок без иконки (вреда нет, читается одинаково); ссылка
`tel:` собирается из сохранённого номера без нормализации, как и в карточке входящего контакта; модалка не получила
`role="dialog"` и ловушку фокуса — это давняя особенность компонента, а не регрессия партии, и менять её нужно отдельной
задачей с проверкой клавиатурной навигации. Проверки CSS-классов в тестах связаны с реализацией, но это осознанная
регрессия на стиль, а не проверка поведения.

## Тесты

Два новых feature-теста: `test_user_info_modal_escapes_phone_markup`,
`test_incoming_location_with_non_numeric_metadata_does_not_build_map_link`. Всего 381 тест / 971 утверждение.

## Нюансы

Изменение подписи `remove_chat` и внешнего вида шапки — только текст и оформление, публичные сигнатуры и ключи конфига
не тронуты; для мажорного v2.0.0 это допустимо и описано в release notes. README и release notes сверены с кодом,
таблица «Истории изменений» осталась целой (одна строка на версию).
