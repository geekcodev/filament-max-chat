# v1.0.8

## Множественные вложения

Оператор теперь может прикрепить к одному ответу несколько файлов: поле загрузки принимает до 10 файлов (колонка
`attachments.*` в валидации, лимит задаётся блоком `attachments.*` конфига — лимит размера и whitelist mime-типов
работают для каждого файла). Внутренности диалога строятся через `MaxChatSender::sendAttachments()`, который загружает
каждое вложение в MAX и упаковывает их в одно сообщение с общей подписью.

Хранение тоже переработано: вложение больше не одно, а список. Колонка `attachment` в `max_chat_messages` теперь всегда
содержит массив (список) метаданных вместо одиночной записи. `MaxAttachmentStore::storeFromIncoming()` возвращает все
медиа из апдейта, а не только первое, поэтому входящее сообщение с несколькими картинками/файлами сохраняется целиком.

## Адресация вложений

Роут раздачи вложений переведён на чистый сегмент пути с индексом: `/chat-attachments/{message}/{index}` вместо прежнего
префикса `?index=` в параметрах. Это позволяет отдавать каждое вложение отдельно с сохранением права `permissions.view`.
URL для конкретного файла внутри сообщения можно получить через новый метод модели `MaxMessage::attachmentAt($index)`.

Для удобства на модели появились два метода: `attachments()` возвращает список метаданных (всегда массив, даже если
раньше в БД лежала одиночная запись), а `attachmentAt($index)` — один элемент по индексу. Превью диалога в списке бесед
при нескольких вложениях теперь показывает счётчик, например «📷 Фото +2».

## Редактор: предпросмотр и вставка ссылки

В редакторе ответа появился переключатель «Предпросмотр ⇄ Исходник»: можно посмотреть, как HTML-сообщение будет
выглядеть у пользователя, не отправляя его. Превью рендерится отсанитизированным тем же `TextSanitizer`, что и перед
отправкой, поэтому картинка «что вижу, то и уйдёт» — результат предпросмотра совпадает с реальным форматированием MAX.

Кнопка «Вставить ссылку» теперь запрашивает подписанный текст ссылки и URL через простой ввод, оборачивая выбранный
текст в `<a>` — ветку создавать вручную не нужно.

## Интерфейс и тесты

Из интерфейса убраны стилизующие эмодзи (скрепка, цепь, иконка документа) — они заменены на SVG-иконки и текстовые
подписи, что аккуратнее выглядит на разных темах и не зависит от шрифта. Убраны неиспользуемые строки локализации.

Покрытие тестами доведено с 95.7% до 98% строк; добавлены тесты на множественные вложения, новые методы модели, ветки
`MaxAttachmentStore`, поведение редактора и профильные джобы.

## Конфигурация

Прикрепление до 10 файлов за раз регулируется блоком `attachments.*` (как и раньше — размер и whitelist mime-типов), без
новых ключей конфигурации.
